# 피치퍼펙트

보컬팀이 매주 바뀌는 곡을 음정 처짐 없이 부르도록 돕는 웹앱(PWA). 아이폰과 안드로이드 브라우저에서 열고 홈 화면에 추가해서 써요.

- **롱톤**: 한 음을 길게 부르면 처음보다 몇 cent 처졌는지 실시간으로 보여줘요.
- **곡 추가**: 파트별 기준 멜로디를 녹음하거나 오디오 파일로 불러오면 음정 목표선을 만들어요.
- **곡 연습**: 목표선 위에 내 음정을 그리고, 끝나면 정확도와 긴 음 처짐을 알려줘요.

빌드 과정 없이 정적 파일만으로 동작해요. 로컬 실행: `python3 -m http.server` 후 `http://localhost:8000`.
마이크는 HTTPS(또는 localhost)에서만 켜져요.
